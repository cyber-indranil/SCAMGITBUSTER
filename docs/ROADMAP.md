# Roadmap

The following are **development objectives**, not current production assurances.

## Near-term

- Investigate the transient login-versus-family-list authorization mismatch.
- Improve selection of source-bearing repositories and report why candidates fail verification.
- Recover or reference previously preserved artifacts when a live repository is inaccessible.
- Preserve investigator-nominated priorities without suppressing alternative leads.
- Treat superficial inventory as insufficient evidence rather than no-adverse-evidence.
- Improve report readability and include a coverage/uncertainty summary by repository.

## Research directions

- Context-aware source analysis distinguishing collection, transmission and benign application flows.
- Static Android artifact correlation with explicit provenance and confidence boundaries.
- Corroboration of infrastructure and impersonation patterns across independent observations.
- Human-labelled evaluation sets for precision, recall, false positives and false negatives.
- Reproducible analyst review and evidence lifecycle verification.

## Non-goals

- Automatically accusing repository owners or identifying criminals from filenames or search hits.
- Exploiting public repositories, executing malicious APKs, covert surveillance or unrestricted automated data collection.
- Publishing private case material or turning investigative leads into public allegations.
