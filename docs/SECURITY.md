# Security, Privacy and Disclosure

## What is intentionally not public

The SCAMGITBUSTER GitHub showcase does not distribute application source, access controls, service units, hosting configuration, integration secrets, passwords, control keys, real investigative records, private evidence manifests, internal database exports or live case hashes.

## Public issue hygiene

Please **do not** publish live credentials, personal information, victim data, malware samples, suspicious payloads, private investigation details or sensitive URLs in a public issue. Coordinate sensitive disclosures with the project maintainer through an appropriate private channel.

## Operational boundaries

- Authorized sessions and role checks govern protected investigator functions.
- Public-source collection is bounded and subject to provider access controls.
- Static analysis does not execute recovered samples.
- Reported intelligence must be independently verified.
- The source of a GitHub search result must not be assumed to be a participant in fraud.

## Project status

Privately operated development system; not a publicly hosted security service or official government reporting channel. No security warranty or forensic certification is asserted.
